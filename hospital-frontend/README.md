# فرانت‌اند نوبت‌دهی بیمارستان (React + Vite)

## اجرا
1. بک‌اند را اجرا کنید (پورت 8080).
2. در همین پوشه:
   npm install
   npm run dev
3. بروید به http://localhost:5173  (پورت باید همین باشد چون CORS بک‌اند فقط همین آدرس را قبول می‌کند)

آدرس بک‌اند در فایل .env قابل تغییر است (نمونه: .env.example).
